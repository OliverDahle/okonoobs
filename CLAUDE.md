# Prosjekt: økonoobs.no

## Regler
- Du har full frihet til å velge teknologi og struktur
- Output MÅ havne i `dist/`-mappen etter build
- Hvis du bruker et framework (React, Vue, etc.), sett opp package.json med `npm run build` som outputter til `dist/`
- Hvis du foretrekker vanilla HTML/CSS/JS, skriv direkte i `dist/`
- Bruk moderne, responsivt design (mobile-first)
- Bruk norsk språk i alt innhold
- Design skal være profesjonelt og presentabelt for en jury

## Stack
- Velg fritt: vanilla, React, Vue, Svelte, Tailwind, etc.
- Tillatte CDN-er hvis vanilla: Google Fonts, Font Awesome, Chart.js, AOS, Three.js, D3.js
- Eneste krav: `npm run build` må outputte til `dist/`

## Miljø
- Node.js 20 tilgjengelig i CI
- Ingen backend — kun statisk output
