# Prosjekt: økonoobs.no

## Regler
- Skriv ALL kode som én enkelt `dist/index.html`-fil (inline CSS + JS)
- Bruk moderne, responsivt design (mobile-first)
- Bruk norsk språk i alt innhold
- Ingen backend, ingen npm, ingen build-steg — ren statisk HTML
- Design skal være profesjonelt og presentabelt for en jury
- Bruk moderne CSS (grid, flexbox, clamp(), scroll-snap om passende)
- Inkluder smooth scroll, subtle animasjoner, og god typografi

## Stack
- HTML5 + inline CSS + vanilla JS
- Tillatte CDN-er: Google Fonts, Font Awesome, Chart.js, AOS (animate on scroll)
